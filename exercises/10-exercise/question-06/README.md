# question-06 - Asal Sayı İşlemleri

## Problem Açıklaması

Belirli bir sayıdan sonra gelen, bir sonraki asal sayıyı bulan bir metot yazın. Verilen sayı bir asal sayıysa, sayının kendisini döndürün.

## Örnek Kullanım / Mantık

Sayılar bölen denetimiyle asallık açısından kontrol edilir; soruya göre asal adetleri/toplamı veya sonraki asal bulunur. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
