# Soru 5 - Kelimenin Çoğul Olup Olmadığı

## Problem Açıklaması

Bir kelimenin çoğul olup olmadığını kontrol eden bir metot yazınız.

## Örnek Kullanım / Mantık

Kelimenin sonundaki çoğul eki kontrol edilir ve çoğulluk sonucu bildirilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
