# Soru 3 - Dizide Eleman Arama

## Problem Açıklaması

Belirli bir sayının bir sayı dizisinde olup olmadığını kontrol eden bir C# programı yazın.

## Örnek Kullanım / Mantık

Dizi sırayla taranır ve aranan değerin bulunup bulunmadığı bildirilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
