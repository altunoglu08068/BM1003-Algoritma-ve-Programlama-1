# Soru 5 - Sıcaklık Dönüştürme

## Problem Açıklaması

Santigrat dereceyi Fahrenheit'e çeviren bir metot yazınız.

## Örnek Kullanım / Mantık

Seçilen sıcaklık birimine göre dönüşüm formülü uygulanır ve karşılık gelen değer yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
