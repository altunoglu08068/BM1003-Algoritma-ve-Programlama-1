# question-20 - Matris Transpozu

## Problem Açıklaması

2x2 boyutunda bir matrisi parametre olarak alan ve transpozunu alıp sonucu geriye döndüren bir metot yazınız.

## Örnek Kullanım / Mantık

Satır ve sütun indisleri yer değiştirilerek matrisin transpozu oluşturulur. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
