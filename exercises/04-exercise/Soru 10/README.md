# Soru 10 - Armstrong Sayısı Kontrolü

## Problem Açıklaması

Girilen üç basamaklı sayının rakamlarının küpleri toplamının sayının kendisine eşit olup olmadığını kontrol edin.

## Örnek Kullanım / Mantık

Üç basamaklı sayının rakamları ayrıştırılıp küpleri toplanır; toplamın özgün sayıya eşitliği kontrol edilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
