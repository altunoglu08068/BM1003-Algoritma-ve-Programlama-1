# question-01 - Kareler Toplamı

## Problem Açıklaması

Kullanıcının girdiği 2 sayının karelerinin toplamını hesaplayıp geri döndüren bir metot yazınız.

## Örnek Kullanım / Mantık

İki sayının kareleri hesaplanıp toplanır; toplam sonuç olarak döndürülür veya yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
