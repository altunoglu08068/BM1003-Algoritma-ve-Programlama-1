# question-04 - (x + y) × z Formülünü Hesaplama

## Problem Açıklaması

Üç parametre için (x + y) × z formülünün sonucunu hesaplayıp döndürün.

## Örnek Kullanım / Mantık

İlk iki değer toplanır, ara sonuç üçüncü değerle çarpılır ve metot sonucu döndürür. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
