# question-07 - Doğum Yılından Yaş Hesaplama

## Problem Açıklaması

Doğum yılını parametre alan bir metotla kişinin yaşını hesaplayıp ekrana yazdırın.

## Örnek Kullanım / Mantık

Geçerli doğum yılı mevcut yıldan çıkarılır; fark kişinin yaşı olarak gösterilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
