# Soru 3 - 100’e En Yakın Sayıyı Bulma

## Problem Açıklaması

Verilen iki tam sayıdan 100’e daha yakın olanı bulun; sayılar eşitse 0 döndürün.

## Örnek Kullanım / Mantık

Sayıların 100’e mutlak uzaklıkları karşılaştırılır; eşit girişler için özel olarak 0 döndürülür. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
