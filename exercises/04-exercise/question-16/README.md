# question-16 - s = x + y² Formülünü Hesaplama

## Problem Açıklaması

Girilen x ve y değerleri için s = x + y² denkleminin sonucunu hesaplayın.

## Örnek Kullanım / Mantık

Önce y’nin karesi alınır, ardından x ile toplanarak s sonucu üretilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
