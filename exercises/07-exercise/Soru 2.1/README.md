# Soru 2.1 - Diziyi Ters Sırayla Oluşturma

## Problem Açıklaması

Soru 2’deki dizinin elemanlarını karşılıklı uçlardan eşleştirerek yeni B dizisini oluşturun ve yazdırın.

## Örnek Kullanım / Mantık

A dizisi baştan ve sondan eş zamanlı okunur; elemanlar ters sırayla B dizisine kopyalanır. Kullanıcı girdisi gerekmez; kaynakta tanımlı örnek değerler işlenir ve elde edilen sonuç konsola yazdırılır.
