# Soru 1.2 - Köşegenlerin Toplamı ve Çarpımı

## Problem Açıklaması

Kare matrisin ana köşegenindeki değerleri toplayın ve yardımcı köşegenindeki değerleri çarpın.

## Örnek Kullanım / Mantık

Ana köşegen için satır indisi sütun indisine, yardımcı köşegen için sütun indisi N−1−satır indisine eşit olan hücreler işlenir. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
