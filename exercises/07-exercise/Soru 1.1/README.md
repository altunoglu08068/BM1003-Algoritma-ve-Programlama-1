# Soru 1.1 - Ana Köşegen Toplamı

## Problem Açıklaması

Rastgele oluşturulan kare matrisin ana köşegeni üzerindeki elemanların toplamını hesaplayın.

## Örnek Kullanım / Mantık

Satır ve sütun indisi eşit olan elemanlar toplanarak ana köşegen toplamı bulunur. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
