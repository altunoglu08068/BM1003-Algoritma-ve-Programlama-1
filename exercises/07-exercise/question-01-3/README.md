# question-01-3 - Köşegenler ve Negatif Eleman Sayısı

## Problem Açıklaması

Kare matrisin köşegen işlemlerini yapın ve matristeki negatif elemanların sayısını bulun.

## Örnek Kullanım / Mantık

Köşegen hücreleri ilgili toplam/çarpım için, tüm hücreler ise negatif değer sayacı için taranır. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
