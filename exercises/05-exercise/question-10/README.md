# question-10 - Palindrom Kontrolü

## Problem Açıklaması

Verilen bir kelimenin palindrom olup olmadığını kontrol eden bir C# programı yazınız. Palindrom, tersten okunuşu ile aynı olan cümle, sözcük ve sayılara denilmektedir.

## Örnek Kullanım / Mantık

Metin düz ve ters sırayla karşılaştırılır; iki gösterim aynıysa palindrom sonucu verilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
