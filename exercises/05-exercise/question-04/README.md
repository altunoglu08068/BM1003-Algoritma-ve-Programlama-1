# question-04 - İlk Dört Elemanda Arama

## Problem Açıklaması

Bir tamsayı dizisindeki ilk 4 öğeden birinin verilen bir öğeye eşit olup olmadığını kontrol eden bir metot yazın.

## Örnek Kullanım / Mantık

Aranan değer yalnızca dizinin ilk dört elemanıyla karşılaştırılır ve eşleşme sonucu döndürülür. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
