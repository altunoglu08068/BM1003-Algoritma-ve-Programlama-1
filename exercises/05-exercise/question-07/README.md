# question-07 - Değerlerin Yerini Değiştirme

## Problem Açıklaması

Bir dizideki ilk ve son elemanların yerini değiştiren ve yeni diziyi döndüren bir metot yazınız.

## Örnek Kullanım / Mantık

İki değişkenin değerleri geçici saklama veya tuple atamasıyla yer değiştirilir. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
