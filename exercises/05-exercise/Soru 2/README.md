# Soru 2 - Metni Küçük Harfe Dönüştürme

## Problem Açıklaması

Metinsel bir ifadedeki büyük harfleri küçük harflere dönüştüren bir metot tanımlayınız.

## Örnek Kullanım / Mantık

Metindeki büyük harfler kültür-duyarlı küçük harf dönüşümüyle çevrilip gösterilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
