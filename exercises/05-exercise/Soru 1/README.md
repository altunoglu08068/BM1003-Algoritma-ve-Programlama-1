# Soru 1 - 3×3 Matrisleri Toplama

## Problem Açıklaması

2 tane 3x3 boyutundaki matrisi parametre olarak alıp toplayan ve sonucu geri döndüren bir metot yazınız.

## Örnek Kullanım / Mantık

İki matrisin aynı satır-sütun konumundaki elemanları toplanarak sonuç matrisi oluşturulur. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
