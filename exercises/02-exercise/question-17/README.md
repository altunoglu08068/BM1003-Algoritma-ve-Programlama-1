# question-17 - Değerlerin Yerini Değiştirme

## Problem Açıklaması

İki basamaklı bir sayının basamaklarının yerini değiştiren ve elde edilen sayının orjinal sayıdan büyük olup olmadığını kontrol eden bir C# programı yazın.

## Örnek Kullanım / Mantık

İki değişkenin değerleri geçici saklama veya tuple atamasıyla yer değiştirilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
