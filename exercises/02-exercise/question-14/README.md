# question-14 - Ortalamanın Üstündeki Değerler

## Problem Açıklaması

Klavyeden girilen 10 adet tamsayı sınav notuna göre, ortalamanın üstünde olanları ekrana yazan programı yazınız.

## Örnek Kullanım / Mantık

Değerlerin ortalaması hesaplanır; ortalamayı aşan elemanlar ayrıca listelenir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
