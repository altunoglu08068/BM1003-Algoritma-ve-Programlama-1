# Soru 2 - Toplam ve Ortalama

## Problem Açıklaması

10 sayıyı kullanıcıdan alıp bunların ortalamasını ve toplamını bulan bir C# programı yazın.

## Örnek Kullanım / Mantık

Girilen değerler bir döngüde toplanır; toplam eleman sayısına bölünerek ortalama bulunur. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
