# question-08 - Rakamlar Toplamı

## Problem Açıklaması

Bir tam sayının rakamlarının toplamını hesaplayan programı yazınız.

## Örnek Kullanım / Mantık

Her basamak aritmetik bölme ve kalan işlemleriyle ayrıştırılır; basamak değerleri toplanıp yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
