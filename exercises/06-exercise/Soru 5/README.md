# Soru 5 - Komşu Dizi Elemanlarını Takas Etme

## Problem Açıklaması

[1, 2, 3, 4, 5, 6] dizisinin komşu eleman çiftlerini takas ederek [2, 1, 4, 3, 6, 5] sonucunu oluşturun.

## Örnek Kullanım / Mantık

Dizi ikişer indis atlayarak dolaşılır ve her komşu çiftin değerleri yer değiştirilir. Kullanıcı girdisi gerekmez; kaynakta tanımlı örnek değerler işlenir ve elde edilen sonuç konsola yazdırılır.
