# question-03-3 - Rastgele Diziyi İstatistiksel İnceleme

## Problem Açıklaması

Rastgele sayı dizisini oluşturup yazdırın; ortalamasını, ortalamadan büyük elemanları ve ortalamaya olan uzaklıklarını hesaplayın.

## Örnek Kullanım / Mantık

Kullanıcı uzunluğu belirler; üretilen dizi için ortalama, ortalamayı aşan elemanlar ve ortalamaya uzaklıklar raporlanır. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
