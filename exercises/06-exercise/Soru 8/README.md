# Soru 8 - Faktöriyel Hesaplama

## Problem Açıklaması

Kullanıcıdan alınan negatif olmayan bir tam sayının faktöriyelini hesaplayın ve sonucu konsola yazdırın.

## Örnek Kullanım / Mantık

Kullanıcıdan negatif olmayan tam sayı alınır; çarpım döngüsüyle faktöriyel hesaplanır ve geçersiz girişler bildirilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
