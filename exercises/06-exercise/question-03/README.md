# question-03 - Rastgele Dizi Ortalaması

## Problem Açıklaması

Kullanıcının belirlediği uzunlukta rastgele sayılardan oluşan bir dizi üretin, elemanları ve ortalamayı yazdırın.

## Örnek Kullanım / Mantık

Kullanıcı dizi uzunluğunu girer; rastgele elemanlar üretilip yazdırılır ve toplam uzunluğa bölünerek ortalama bulunur. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
