# Soru 6 - Alınan string'in tersini yazdıran bir program kodlayınız

## Problem Açıklaması

Kullanıcıdan alınan string'in tersini yazdıran bir program kodlayınız.

## Örnek Kullanım / Mantık

Değerler konsoldan alınır, kaynak koddaki koşul ve hesaplamalarla işlenir ve sonuç konsola yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
