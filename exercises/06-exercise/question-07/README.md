# question-07 - Faktöriyel Hesaplama

## Problem Açıklaması

Kullanıcıdan alınan sayının faktöriyelini ekrana yazdıran bir program yazınız.

## Örnek Kullanım / Mantık

Sıfırdan girilen sayıya kadar tam sayılar çarpılarak faktöriyel bulunur; negatif değerler reddedilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
