# Soru 4 - Rastgele Diziyi Yeniden Düzenleme

## Problem Açıklaması

Kullanıcıdan alınan uzunlukta rastgele sayılardan oluşan bir dizi üretin ve diziyi belirlenen kurala göre yeniden düzenleyerek yazdırın.

## Örnek Kullanım / Mantık

Girilen uzunlukta rastgele dizi oluşturulur; kaynak koddaki indis/eleman kuralı uygulanarak ilk ve sonraki dizi gösterilir. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
