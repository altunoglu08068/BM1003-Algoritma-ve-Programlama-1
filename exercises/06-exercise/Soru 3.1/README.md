# Soru 3.1 - Ortalamanın Üstündeki Rastgele Dizi Elemanları

## Problem Açıklaması

Rastgele sayı dizisini oluşturup yazdırın, ortalamayı ve ortalamadan büyük elemanları gösterin.

## Örnek Kullanım / Mantık

Rastgele dizi üretilip ortalaması hesaplanır; ikinci taramada ortalamayı aşan değerler ve ortalamaya uzaklıkları gösterilir. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
