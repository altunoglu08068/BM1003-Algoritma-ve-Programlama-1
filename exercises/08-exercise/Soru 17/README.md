# Soru 17 - Tam Sayı Dizisini Yazdırma

## Problem Açıklaması

Parametre olarak gönderilen tam sayı dizisinin elemanlarını ekrana yazdıran bir metot oluşturun.

## Örnek Kullanım / Mantık

Dizi metotta dolaşılarak elemanları sırasıyla konsola yazdırılır. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
