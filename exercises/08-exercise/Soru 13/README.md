# Soru 13 - Dairenin Alanı ve Çevresi

## Problem Açıklaması

Yarıçapı parametre alan metotlarla dairenin çevresini ve alanını hesaplayıp ekrana yazdırın.

## Örnek Kullanım / Mantık

Pozitif yarıçap alınır; ayrı alan ve çevre metotlarıyla sonuçlar hesaplanıp iki basamakla gösterilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
