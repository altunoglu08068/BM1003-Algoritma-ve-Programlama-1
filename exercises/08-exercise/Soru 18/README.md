## Problem Açıklaması

İki boyutlu dizideki pozitif ve negatif sayıların adetlerini ayrı ayrı hesaplayıp yazdırın.

Matrisin bütün hücreleri iç içe döngülerle gezilir; işarete göre ilgili sayaç artırılır. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
