# Soru 2 - Üç Sayının En Büyüğünü Bulma

## Problem Açıklaması

Bir metotla verilen üç tam sayı arasındaki en büyük değeri bulun ve sonucu döndürün.

## Örnek Kullanım / Mantık

Üç parametre karşılaştırılır; eşitlikler korunarak maksimum değer metottan döndürülür. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
