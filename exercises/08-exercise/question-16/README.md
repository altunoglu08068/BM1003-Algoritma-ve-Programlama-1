# question-16 - s = x + y² Formülünü Hesaplama

## Problem Açıklaması

x ve y için s = x + y² denkleminin sonucunu hesaplayan bir metot yazın.

## Örnek Kullanım / Mantık

Önce y’nin karesi alınır, sonra x eklenir ve hesaplanan s değeri gösterilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
