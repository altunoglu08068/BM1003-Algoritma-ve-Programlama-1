# question-04 - (x + y) × z Formülünü Hesaplama

## Problem Açıklaması

x, y ve z parametreleri için (x + y) × z işlemini hesaplayan bir metot yazın.

## Örnek Kullanım / Mantık

x ve y toplanır; toplam z ile çarpılarak sonuç elde edilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
