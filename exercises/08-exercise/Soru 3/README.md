# Soru 3 - 100’e En Yakın Sayıyı Bulma

## Problem Açıklaması

Verilen iki tam sayıdan 100’e daha yakın olanı bulun; sayılar eşitse 0 döndürün.

## Örnek Kullanım / Mantık

İki değerin 100’e uzaklıkları karşılaştırılır; eşit sayı girişi için 0 sonucu üretilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
