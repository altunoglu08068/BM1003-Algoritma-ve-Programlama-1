# Soru 7 - Üçgen Türünü Belirleme

## Problem Açıklaması

Bir üçgenin Eşkenar, İkizkenar veya Çeşitkenar olup olmadığını kontrol eden programı yazın.

## Örnek Kullanım / Mantık

Kenar uzunlukları karşılaştırılarak üçgen eşkenar, ikizkenar veya çeşitkenar olarak sınıflandırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
