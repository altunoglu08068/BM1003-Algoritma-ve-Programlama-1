# question-24 - Bölme ve Kalan

## Problem Açıklaması

İki tamsayı a ve b (b ≠ 0) için bölüm ve kalanı hesaplayıp yazdırınız.

## Örnek Kullanım / Mantık

Bölme öncesinde sıfır payda kontrol edilir; bölüm ve/veya kalan güvenli biçimde hesaplanır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
