# Soru 11 - Dört İşlem Hesaplama

## Problem Açıklaması

Kullanıcıdan iki sayı ve bir işlem (+, -, *, /) seçmesini isteyen, buna göre sonucu hesaplayan programı yazınız.

## Örnek Kullanım / Mantık

İki sayı ve işlem seçimi alınır; seçilen toplama, çıkarma, çarpma veya bölme işlemi uygulanır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
