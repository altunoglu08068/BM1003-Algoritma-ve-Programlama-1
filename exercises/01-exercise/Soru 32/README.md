# Soru 32 - ATM Menü İşlemleri

## Problem Açıklaması

ATM menüsünde para yatırma, para çekme, bakiye görüntüleme ve çıkış işlemlerini kullanıcı seçimine göre gerçekleştirin.

## Örnek Kullanım / Mantık

Menü seçimiyle yatırma, çekme ve bakiye görüntüleme işlemleri yürütülür; kullanıcı çıkış yapana kadar menü tekrar sunulur. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
