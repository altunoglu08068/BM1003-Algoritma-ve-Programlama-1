# Soru 20 - Sıfıra Bölme Kontrolü

## Problem Açıklaması

İki sayı alın; ikinci sayı sıfır değilse bölme sonucunu, sıfırsa hata mesajını gösterin.

## Örnek Kullanım / Mantık

Bölen işlemden önce kontrol edilir; sıfır değilse bölme yapılır, aksi durumda sıfıra bölme uyarısı verilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
