# Soru 21 - Harf Notunu Açıklama

## Problem Açıklaması

Kullanıcıdan AA, BB, CC, FF gibi bir not alınsın. Buna göre ekrana açıklama yazdırınız. "AA → Çok İyi" "BB → İyi" "CC → Orta" "FF → Başarısız".

## Örnek Kullanım / Mantık

Girilen harf notu eşleştirme yapısıyla değerlendirilir ve notun açıklaması yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
