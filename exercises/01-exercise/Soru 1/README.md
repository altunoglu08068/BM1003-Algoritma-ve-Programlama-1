# Soru 1 - Sayıları Sıralama

## Problem Açıklaması

Klavyeden girilen 3 sayıyı küçükten büyüğe doğru ekrana yazan programı yazınız.

## Örnek Kullanım / Mantık

Sayılar karşılaştırılarak küçükten büyüğe sıralanır ve sıralı değerler ekrana yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
