# Soru 16 - Pozitif ve Çift Sayı Kontrolü

## Problem Açıklaması

Kullanıcıdan alınan sayının hem pozitif hem de çift olup olmadığını bulan programı yazınız.

## Örnek Kullanım / Mantık

Sayının pozitifliği ve çiftliği ayrı koşullarla kontrol edilip sonuç birleştirilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
