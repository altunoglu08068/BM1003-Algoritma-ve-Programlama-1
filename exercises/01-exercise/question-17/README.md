# question-17 - Kullanıcı Girişi Kontrolü

## Problem Açıklaması

Kullanıcıdan kullanıcı adı ve şifre alınsın. Eğer kullanıcı adı = "admin" ve şifre = "1234" ise “Giriş başarılı” Aksi halde “Hatalı giriş” yazan programı yapınız.

## Örnek Kullanım / Mantık

Kullanıcı adı ve parola beklenen değerlerle karşılaştırılır; giriş sonucu gösterilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
