# Soru 31 - Beden Kitle İndeksi

## Problem Açıklaması

Kullanıcıdan boy (metre) ve kilo (kilogram) bilgileri alarak beden kitle indeksini hesaplayın ve sonucu sınıflandırın.

## Örnek Kullanım / Mantık

Boy ve kilo geçerli pozitif sayılar olarak doğrulanır; BMI, kilo / boy² formülüyle hesaplanıp ekrana yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
