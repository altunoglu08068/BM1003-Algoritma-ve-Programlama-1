# question-33 - Taksi Ücreti Hesaplama

## Problem Açıklaması

Taksi ücreti: Açılış 30 TL + km başı 12 TL. Eğer saat (0–23) 22–06 arasındaysa toplam ücrete %20 gece zammı uygulayınız.

## Örnek Kullanım / Mantık

Açılış ücreti ve mesafe tutarı toplanır; gece saatlerinde zam uygulanır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
