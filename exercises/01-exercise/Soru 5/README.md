# Soru 5 - Eşitlik Kontrolü

## Problem Açıklaması

İki tam sayıyı kabul eden ve eşit olup olmadıklarını kontrol eden programı yazın.

## Örnek Kullanım / Mantık

İki değer karşılaştırılır; eşitlik durumuna uygun sonuç ekrana yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
