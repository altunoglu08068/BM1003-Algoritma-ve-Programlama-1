# Soru 19 - Mutlak Değer ve İşaret

## Problem Açıklaması

Kullanıcıdan bir sayı alınız. Sayı negatifse işaretini pozitife çevirerek mutlak değerini ekrana yazdırınız.

## Örnek Kullanım / Mantık

Sayının mutlak değeri ile pozitif, negatif veya sıfır oluşu belirlenip birlikte gösterilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
