# Soru 15 - Aralık Kontrolü

## Problem Açıklaması

Kullanıcıdan alınan sayının 0 ile 100 arasında olup olmadığını kontrol eden programı yazınız.

## Örnek Kullanım / Mantık

Girilen değer alt ve üst sınırlarla karşılaştırılır; aralıkta olup olmadığı bildirilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
