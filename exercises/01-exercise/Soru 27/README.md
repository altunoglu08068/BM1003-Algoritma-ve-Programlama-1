# Soru 27 - Üçgen Geçerliliği

## Problem Açıklaması

Bir üçgenin geçerli olup olmadığını kontrol ediniz (üçgen eşitsizliği). Geçerli değilse “Geçersiz üçgen” yazdırınız (alan/tür hesaplaması yok).

## Örnek Kullanım / Mantık

Üç kenar uzunluğu üçgen eşitsizliği koşullarıyla kontrol edilir; geçerli değilse uyarı verilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
