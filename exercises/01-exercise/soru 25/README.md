# soru 25 - Dakikayı Saat ve Dakikaya Çevirme

## Problem Açıklaması

Kullanıcıdan toplam dakika alınız; saat ve dakika cinsinden yazdırınız. (Örn. 135 → 2 saat 15 dakika).

## Örnek Kullanım / Mantık

Toplam dakika 60’a bölünerek saat ve kalan dakika bulunur. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
