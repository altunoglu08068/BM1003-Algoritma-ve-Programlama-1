# Soru 13 - Artık Yıl Kontrolü

## Problem Açıklaması

Kullanıcıdan yıl bilgisini alıp, o yılın artık yıl olup olmadığını bulan programı yazınız. Kural: Yıl 4’e tam bölünüyorsa artık yıldır.

## Örnek Kullanım / Mantık

Girilen yıl, artık yıl koşuluna göre kontrol edilerek uygun sonuç yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
