# Soru 29 - Kesirleri Karşılaştırma

## Problem Açıklaması

Kullanıcıdan iki kesir alınız: birinci kesir için a ve b, ikinci kesir için c ve d değerlerini (pay ve payda) giriniz. Paydalar 0 olamaz. Girilen iki kesri karşılaştırarak, birinci kesir büyükse "a/b > c/d", küçükse "a/b < c/d", eşitse "a/b = c/d" şeklinde sonucu ekrana yazdırınız.

## Örnek Kullanım / Mantık

Paydalar sıfırdan farklı tutulur; kesirler karşılaştırılarak büyüklük ilişkisi yazdırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
