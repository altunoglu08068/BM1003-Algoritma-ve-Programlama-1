# question-03 - Haftanın Gününü Bulma

## Problem Açıklaması

Klavyeden girilen gün adına göre haftanın kaçıncı günü olduğunu bulan programı yazınız.

## Örnek Kullanım / Mantık

Girilen gün adı haftanın günleriyle eşleştirilir ve karşılık gelen sıra numarası gösterilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
