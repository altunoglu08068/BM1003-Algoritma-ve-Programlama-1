# question-08 - Ortalamaya Eşit Elemanları Sayma

## Problem Açıklaması

100 elemanlı bir dizi tanımlayınız. Bu diziye 0-10 arasında rastgele sayılar atayın. Dizideki elemanların ortalamasını bulup, dizi elemanlarından kaç tanesinin elde edilen bu ortalama değerine eşit olduğunu hesaplayınız.

## Örnek Kullanım / Mantık

Dizi ortalaması bulunur; ortalamaya eşit olan elemanların sayısı hesaplanır. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
