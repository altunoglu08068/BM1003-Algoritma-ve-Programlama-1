# question-13 - Dizide Eleman Arama

## Problem Açıklaması

Tam sayılardan oluşan bir dizide aranan elemanın olup olmadığını bulan bir programı yazınız.

## Örnek Kullanım / Mantık

Dizi sırayla taranır ve aranan değerin bulunup bulunmadığı bildirilir. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
