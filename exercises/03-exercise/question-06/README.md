# question-06 - 50 Eşiğine Göre Dizi Toplamları Oranı

## Problem Açıklaması

Rastgele oluşturulan dizide 50’den büyük ve 50’den küçük elemanların toplamlarının oranını hesaplayın.

## Örnek Kullanım / Mantık

Dizi elemanları 50 eşiğine göre iki toplamda biriktirilir; büyüklerin toplamı küçüklerin toplamına bölünür. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
