# question-17 - Sıfırları Dizinin Sonuna Taşıma

## Problem Açıklaması

Tüm 5 değerlerini 0 ile değiştirdikten sonra tüm sıfırları sağa kaydırarak yeni bir dizi oluşturan bir C# programı yazın.

## Örnek Kullanım / Mantık

Belirtilen değerler sıfıra dönüştürülür; sıfır olmayanlar korunarak sıfırlar sona taşınır. Kullanıcı girdisi gerekmez; kaynakta tanımlı örnek değerler işlenir ve elde edilen sonuç konsola yazdırılır.
