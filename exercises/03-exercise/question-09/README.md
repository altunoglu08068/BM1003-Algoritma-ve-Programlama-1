# question-09 - Koşulu Sağlayan Sayıları Sayma

## Problem Açıklaması

Girilen bir cümlede, girilen bir karakterden kaç tane olduğunu bulan programı yazınız.

## Örnek Kullanım / Mantık

Belirtilen aralıktaki sayılar döngüyle incelenir; koşulu sağlayanların adedi sayılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
