# Soru 12 - Matrisi Tek Boyutlu Diziye Dönüştürme

## Problem Açıklaması

İki boyutlu dizinin elemanlarını bir boyutlu diziye aktararak her iki gösterimi de yazdırın.

## Örnek Kullanım / Mantık

Matris satır satır dolaşılır; elemanlar sıraları korunarak tek boyutlu diziye kopyalanır. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
