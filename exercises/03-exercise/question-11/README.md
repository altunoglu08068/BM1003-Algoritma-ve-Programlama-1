# question-11 - Dizi ve Matris Dönüşümü

## Problem Açıklaması

2 x 3 boyutunda bir matris oluşturup, dışarıdan değer girilen ve matrisi ekrana yazdıran bir program yazınız.

## Örnek Kullanım / Mantık

Elemanlar satır-sütun düzeniyle okunur veya iki boyutlu yapı tek boyutlu diziye aktarılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
