# Soru 23 - Karekök Hesaplama

## Problem Açıklaması

Girilen bir sayının yaklaşık olarak kare kökünü hesaplayan programı yazınız.

## Örnek Kullanım / Mantık

Girilen sayı için karekök değeri hesaplanır veya yaklaşık değer üreten yöntem uygulanır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
