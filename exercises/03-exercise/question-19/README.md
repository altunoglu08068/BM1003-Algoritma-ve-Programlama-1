# question-19 - Aralık Kontrolü

## Problem Açıklaması

10 ile 1000 arasındaki tam kare sayıları ekrana yazdıran programı yazınız. (Tam kare, karekökü bir doğal sayı olan tam sayılara denir. 0, 1, 4, 9, 16, 25, 36, 49... tam kare sayılara örnektir.).

## Örnek Kullanım / Mantık

Girilen değer alt ve üst sınırlarla karşılaştırılır; aralıkta olup olmadığı bildirilir. Kullanıcı girdisi gerekmez; kaynakta tanımlı örnek değerler işlenir ve elde edilen sonuç konsola yazdırılır.
