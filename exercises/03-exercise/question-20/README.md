# question-20 - Kuvvet Hesaplama

## Problem Açıklaması

Girilen bir sayının 5’in kuvveti olup olmadığını hesaplayınız.

## Örnek Kullanım / Mantık

Taban ve üs kullanılarak kuvvet hesaplanır; uygun özel durumlar da değerlendirilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
