# Soru 18 - Onluktan İkiliye Dönüştürme

## Problem Açıklaması

Onluk tabanda bir sayıyı ikili sayıya çeviren bir program yazınız.

## Örnek Kullanım / Mantık

Sayı 2’ye art arda bölünür ve kalanlar ters sırayla okunarak ikili gösterim elde edilir. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
