# question-15 - Diziyi En Büyük Değerle Doldurma

## Problem Açıklaması

Belirli bir tamsayı dizisindeki maksimum öğeyi bulan, tüm öğeleri maksimum öğeyle değiştiren bir C# programı yazın.

## Örnek Kullanım / Mantık

Dizinin maksimum elemanı bulunur ve dizi elemanları bu değerle değiştirilir. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
