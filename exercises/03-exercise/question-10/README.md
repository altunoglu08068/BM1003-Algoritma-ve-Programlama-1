# question-10 - Karakter Türünü Belirleme

## Problem Açıklaması

Klavyeden girilen maksimum 20 karakterli bir kelimedeki sesli harflerin sayısının toplam karakter sayısına göre oranını hesaplayınız.

## Örnek Kullanım / Mantık

Girilen karakter harf/rakam/sembol ya da sesli harf koşullarına göre sınıflandırılır. Kullanıcı, konsol istemlerinde belirtilen sayısal/metinsel değerleri girer; programın hesapladığı veya kontrol ettiği sonuç ekranda gösterilir.
