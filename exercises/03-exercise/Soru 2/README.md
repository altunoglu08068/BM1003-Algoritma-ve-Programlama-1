# Soru 2 - Eşikten Küçük Dizi Elemanları

## Problem Açıklaması

Rastgele sayılarla oluşturulan 20 elemanlı bir dizinin, elemanlarından kaç tanesinin dışarıdan girilen bir sayıdan küçük olduğunu bulunuz.

## Örnek Kullanım / Mantık

Rastgele oluşturulan dizi taranır ve eşik değerinden küçük elemanlar sayılır. Kullanıcı, konsoldaki istemlere göre gerekli girdileri (varsa dizi boyutunu/eşiği) verir; rastgele değerler program tarafından üretilir ve sonuç konsola yazdırılır.
