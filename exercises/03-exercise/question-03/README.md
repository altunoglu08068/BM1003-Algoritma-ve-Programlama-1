# question-03 - Çift ve Tek Elemanların Toplam Oranı

## Problem Açıklaması

Rastgele sayılarla oluşturulan 20 elemanlı bir dizinin çift olanlarının toplamının tek olanlarının toplamına oranını bulunuz.

## Örnek Kullanım / Mantık

Dizideki çift ve tek elemanlar ayrı ayrı toplanır; iki toplamın oranı hesaplanır. Kullanıcı girdisi gerekmez; program değerleri rastgele üretir, sorudaki işlemi uygular ve sonucu konsolda gösterir.
