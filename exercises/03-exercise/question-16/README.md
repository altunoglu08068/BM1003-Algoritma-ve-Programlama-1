# question-16 - Dizideki Değerlerin Sayısını Karşılaştırma

## Problem Açıklaması

3'lerin sayısının 5'lerden büyük olup olmadığını kontrol eden bir C# Sharp programı yazın.

## Örnek Kullanım / Mantık

Dizide 3 ve 5 değerlerinin adetleri sayılır ve iki adet karşılaştırılır. Kullanıcı girdisi gerekmez; kaynakta tanımlı örnek değerler işlenir ve elde edilen sonuç konsola yazdırılır.
