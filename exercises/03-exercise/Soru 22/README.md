# Soru 22 - Asal Sayı İşlemleri

## Problem Açıklaması

1 - 100 arasında kaç asal sayı vardır bulunuz.

## Örnek Kullanım / Mantık

Sayılar bölen denetimiyle asallık açısından kontrol edilir; soruya göre asal adetleri/toplamı veya sonraki asal bulunur. Kullanıcı girdisi gerekmez; kaynakta tanımlı örnek değerler işlenir ve elde edilen sonuç konsola yazdırılır.
