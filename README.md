## Çalıştırma

.NET 9 SDK'nın kurulu olduğundan emin olun. Bir çözümü çalıştırmak için terminalde ilgili proje klasörüne geçip `dotnet run` komutunu kullanın:

```bash
cd "exercises/01-exercise/Soru 1/soru1"
dotnet run
```

Ödev projesini çalıştırmak için:

```bash
cd "assignments/assignment-06/ödev6"
dotnet run
```

Bir proje klasöründeyken derlemek için `dotnet build` komutu da kullanılabilir. Soru ve proje klasörleri bağımsız olduğundan, komutları çalıştırmadan önce ilgili klasöre geçin.
